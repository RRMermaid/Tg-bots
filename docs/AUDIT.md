PostgreSQL не было: выводы о коде подтверждены исходниками, а не серверными логами.

bot.py относится к отдельному боту поездки. Он не был причиной конфликтов
«Налегке». В нём обнаружен опубликованный Telegram-токен; значение вынесено

удаление из новой версии не удаляет его из истории Git.

## Границы текущей проверки
Локальные проверки используют подмену Telegram и OpenAI; SQL-проверки требуют
изолированной PostgreSQL. Актуальная серверная схема, настоящая доставка
Telegram и ответы платного API пока не проверялись.
